If one word had to be erased from the dictionary forever, this entry picks
"thingamajig" — the word for the thing you can't name. Delete it, and the
next time you reach for the word for that... that... you know, the
thingamajig... there is nothing left to reach for. The joke is the hole it
leaves: a language without a word for the things it has no word for.

## Run

```
node main.ts
```

This writes the single word to `/output/entry.txt`.
